# 实验记录模板

复制本文件到 `docs/experiments/YYYYMMDD-实验简名.md` 后填写，使用实际实验日期。待填写和未执行项不得作为实验结论。

## 目标与预期

- 本次要验证的问题：待填写。
- 对应阶段/任务/PR：待填写。
- 通过条件：待填写。

## 版本与环境

- 实验日期、执行人、板卡型号/版本：待填写。
- Git 提交号、分支、未提交修改：待填写。
- 镜像、OFDM 包及 Python/PYNQ 版本：待填写。
- bit/hwh 名称、SHA-256 与来源：待填写。
- 若涉及重建，工具/IP/约束版本：待填写。

## 接线与参数

- 实际射频通道、线缆、衰减和启停顺序：待填写。
- 频点、各观察点采样率、调制、FFT/CP、增益：待填写。
- 采集位置、样本数、I/Q 顺序、数据类型和缩放：待填写。

## 复现步骤

1. 执行入口与初始化步骤：待填写。
2. 运行命令或 Notebook 单元格顺序：待填写。
3. 获取结果与核对方法：待填写。

## 实际结果

- 执行状态：未执行 / 通过 / 失败 / 部分通过（选择并说明）。
- 实际观察与统计口径：待填写。
- 原始数据、图表、日志位置和 SHA-256：待填写。
- 独立重复次数与各次结果：待填写。
- 预期与实际差异：待填写。

## 结论与下一步

- 本次证据支持的结论：待填写。
- 尚不能证明的内容及未解决问题：待填写。
- 下一次只改变哪个变量：待填写。
- 占用板卡结束后的固件与接线状态：待填写。

提交前检查：删除私人地址、登录信息和未经许可的内容；原始大文件留在约定存储位置；在 `docs/progress.md` 添加本记录链接。
